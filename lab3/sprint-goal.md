# Sprint Goal

> Жолооч аялал үүсгэж, зорчигч бүртгүүлээд аялал хайж, суудал захиалж, жолооч захиалгыг хүлээн авах үндсэн урсгалыг ажиллагаатай болгох.

## Яагаад энэ зорилго вэ?

Зорчигч ба жолоочийг холбох урсгал нь системийн хамгийн үндсэн үнэ цэнэ юм. Төлбөр, хүргэлт, үнэлгээ зэрэг бусад боломж бүгд энэ урсгал дээр тулгуурлана.

## Хэмжигдэхүйц амжилтын шалгуур

- Шинэ зорчигч бүртгүүлж, өгөгдлөө хадгалж чадна (US-01).
- Зорчигч явах болон очих чиглэлээ сонгож чадна (US-02).
- Зорчигч сонгосон чиглэлийн боломжит аяллуудыг жагсаалтаар харна (US-03).
- Жолооч шинэ аялал үүсгэж чадна (US-09).
- Жолооч аяллын гарах цаг, сул суудлын тоо, үнийг тохируулна (US-10).
- Зорчигч сонгосон аялалдаа суудал захиалж чадна (US-05).
- Жолооч ирсэн захиалгыг хүлээн авч, захиалгын төлөв шинэчлэгдэнэ (US-11).
- Сонгосон Sprint Backlog-ийн 29 SP-ийн ажлууд Done шалгуурыг хангасан байна.

## Done шалгуур

1. User Story-ийн хүлээн авах шалгуурууд биелсэн.
2. Үндсэн урсгалын тест амжилттай.
3. Форм шалгалт болон алдааны мэдэгдэл ажиллана.
4. Багийн дотоод код хяналт хийгдсэн байна.

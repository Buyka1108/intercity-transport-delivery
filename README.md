# Хот хоорондын тээвэр, машинд дайгдах, дайх, хүргэлтийн үйлчилгээ

## Төслийн тухай

Энэхүү төсөл нь хот дотор болон хот хооронд зорчих зорчигч, жолооч,
ачаа илгээгч болон хүлээн авагчдыг нэг системээр холбох зорилготой.

Системээр дамжуулан хэрэглэгч аялал хайх, суудал захиалах,
жолооч аялал үүсгэх, мөн хот дотор болон хот хооронд
ачаа, илгээмж хүргүүлэх боломжтой байна.

## Төслийн зорилго

Хот хоорондын зорчигч тээвэр, машинд дайгдах болон ачаа,
илгээмж хүргэлтийн үйлчилгээг нэг системд нэгтгэж,
зорчигч, жолооч, илгээгч, хүлээн авагч хоорондын
үйл ажиллагааг хялбарчлах.

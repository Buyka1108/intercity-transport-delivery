\## 3. Сонгосон функц



`lab6/booking.py` доторх `booking\_allowed()` функцийг импортлон шалгасан.



Захиалга дараах нөхцөлд зөвшөөрөгдөнө:



\- Аяллын төлөв OPEN байна.

\- Хүссэн суудлын тоо эерэг бүхэл тоо байна.

\- Хүссэн суудал сул суудлын тооноос хэтрэхгүй байна.

\- Сул суудлын тоо сөрөг биш бүхэл тоо байна.



Энэ функц зөвхөн нөхцөл шалгана. Суудал нөөцлөх болон зэрэгцээ захиалгыг зохицуулахгүй.



\## 4. Тестийн зохион байгуулалт



Тест бүрийг AAA зарчмаар бичсэн:



1\. Arrange — оролтын өгөгдөл бэлтгэнэ.

2\. Act — шалгах функцийг дуудна.

3\. Assert — үр дүнг хүлээгдэж буй утгатай харьцуулна.

\## 7. CI тохиргоо



`.github/workflows/ci.yml` файлын тест ажиллуулах командыг шинэчилсэн:



```yaml

&#x20;     - name: Run tests

&#x20;       run: python -m pytest lab6/tests lab10/tests -v

```



Workflow нь push болон pull request үйл явдлаар Python 3.12 орчинд ажиллана.



Өмнөх Lab 6-ын 18 тест болон Lab 10-ын 6 тестийг хамтад нь шалгана. Тест алдаатай бол pytest тэгээс өөр exit code буцааж, CI-ийн test алхмыг амжилтгүй болгоно.



GitHub дээр ажилласан үр дүнг PR-ийн Checks хэсгээс шалгана. Локал тестийн үр дүн нь CI дээр ажилласны нотолгоог орлохгүй.



\## 8. Дүгнэлт



Захиалгын дүрмийг шалгах зургаан тестийг AAA зарчмаар бичиж, хэвийн хүсэлт, суудлын хязгаар болон аяллын төлөвийг шалгав. Одоо байгаа функцийг импортолсон тул эх кодыг давхардуулаагүй. CI тохиргоонд шинэ тестийн хавтсыг нэмж, өмнөх тестүүдтэй хамт автоматаар шалгахаар тохируулав.

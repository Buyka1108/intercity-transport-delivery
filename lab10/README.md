\## 3. Сонгосон функц



`lab6/booking.py` доторх `booking\_allowed()` функцийг импортлон шалгасан.



Захиалга дараах нөхцөлд зөвшөөрөгдөнө:



\- Аяллын төлөв `OPEN` байна.

\- Хүссэн суудлын тоо эерэг бүхэл тоо байна.

\- Хүссэн суудал сул суудлын тооноос хэтрэхгүй байна.

\- Сул суудлын тоо сөрөг биш бүхэл тоо байна.



Энэ функц зөвхөн нөхцөл шалгана. Суудал нөөцлөх болон зэрэгцээ захиалгыг зохицуулахгүй.



\## 4. Тестийн зохион байгуулалт



Тест бүрийг AAA зарчмаар бичсэн:



1\. \*\*Arrange\*\* — оролтын өгөгдөл бэлтгэнэ.

2\. \*\*Act\*\* — шалгах функцийг дуудна.

3\. \*\*Assert\*\* — үр дүнг хүлээгдэж буй утгатай харьцуулна.



\## 5. Тестийн нөхцөлүүд



| № | Нөхцөл | Оролт: хүссэн, сул суудал, төлөв | Хүлээгдэж буй үр дүн |

|---|---|---|---|

| 1 | Нэг суудлын хэвийн хүсэлт | `1, 3, "OPEN"` | `True` |

| 2 | Олон суудлын хэвийн хүсэлт | `2, 5, "OPEN"` | `True` |

| 3 | Доод хязгаар: тэг суудал | `0, 3, "OPEN"` | `False` |

| 4 | Дээд хязгаар: багтаамжтай тэнцүү | `3, 3, "OPEN"` | `True` |

| 5 | Дээд хязгаараас нэгээр их | `4, 3, "OPEN"` | `False` |

| 6 | Хаалттай аялал | `1, 3, "CLOSED"` | `False` |



Тестийн файл: `tests/test\_booking.py`.



Хэвийн нөхцөлийн хоёр, хязгаарын гурван, аяллын төлөвийн нэг тест бичсэн. Функц нь өгөгдлийн сан, гадаад API дуудахгүй тул mock шаардлагагүй.

\## 7. CI тохиргоо



`.github/workflows/ci.yml` файлын тест ажиллуулах командыг шинэчилсэн:



```yaml

&#x20;     - name: Run tests

&#x20;       run: python -m pytest lab6/tests lab10/tests -v

```



Workflow нь `push` болон `pull\_request` үйл явдлаар Python 3.12 орчинд ажиллана. Эхлээд repository-ийн кодыг авч, шаардлагатай санг суулгаад тестүүдийг ажиллуулна.



Өмнөх Lab 6-ын 18 тест болон Lab 10-ын 6 тест буюу нийт 24 тестийг хамтад нь шалгана. Тест алдаатай бол pytest тэгээс өөр exit code буцааж, CI-ийн `test` алхмыг амжилтгүй болгоно.



\### CI-ийн нотолгоо



GitHub Actions дээр ажилласан үр дүнг PR-ийн Checks хэсгээс шалгана. Локал тестийн үр дүн нь CI дээр ажилласны нотолгоог орлохгүй.

\## 8. Review-ийн дагуу хийсэн засвар



Sourcery review нь нийтэлсэн тестийн гаралтад локал хэрэглэгчийн нэр болон төслийн хавтасны зам харагдаж байгааг тэмдэглэсэн.



Үүний дагуу `evidence/test-results.txt` файл дахь локал замуудыг тэмдэглэгээгээр сольсон. Тестийн нэр, шалгалтын үр дүн болон тоог хэвээр үлдээсэн.



Мөн Python-ы автоматаар үүсгэдэг cache файлуудыг Git-д оруулахгүй байхаар `lab10/.gitignore` файлд дараах дүрмийг нэмсэн:



```gitignore

\_\_pycache\_\_/

\*.py\[cod]

.pytest\_cache/

```



Өмнө нь commit-д орсон `.pyc` файлыг Git-ийн бүртгэлээс хассан.

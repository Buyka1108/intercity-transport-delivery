# Kanban самбар ба урсгалын дүрэм

Энэ самбар бол лаб 3-ын Sprint 1 дээр хийсэн **сургалтын симуляц**. Нэг карт = нэг User Story. Story-г жижиг task болгон задлавал task-ийн WIP-г тусдаа тоолох шаардлагатай.

## Багана ба WIP

| Багана | Утга | WIP хязгаар | Шилжүүлэх нөхцөл |
|---|---|---:|---|
| To Do | Сонгосон, эхлээгүй ажил | Тусгай хязгааргүй; энэ дасгалд 7 карт | Шалгуур тодорхой, хэрэгтэй хамаарал бэлэн, In Progress-д зайтай |
| In Progress | Хөгжүүлэлт болон хөгжүүлэгчийн шалгалт | 3 | Шалгуурын хэрэгжилт бэлэн, өөрийн шалгалт хийсэн, Review-д зайтай |
| Review | Код хяналт, хүлээн авах шалгалт | 2 | Хяналтын санал зассан, Done шалгуур хангасан |
| Done | Хүлээн авсан ажил | Хязгааргүй | Картын Done хугацааг бүртгэнэ |

Review дүүрвэл картыг хүчээр шилжүүлэхгүй; In Progress-д blocked гэж тэмдэглэж, WIP-д тоолно. Blocked нь тусдаа багана биш. Саадыг картын тайлбарт шалтгаан, эхэлсэн хугацаа, шийдэх хүнтэй тэмдэглэнэ. Хяналтаас буцаасан ажлын анхны Started хугацааг хадгална; дахин ажилласан хугацаа Cycle Time-д багтана.

## Pull болон өдөр тутмын бодлого

1. Өдөр бүр Done-д ойр байгаа ажлыг эхэлж шалгана: Review → In Progress → To Do.
2. Хамаарал бэлэн, өндөр ач холбогдолтой картыг багана дахь сул зайд татна. Нэг хүн үндсэн нэг хөгжүүлэлтийн карт дээр төвлөрнө.
3. US-03-ийн эцсийн шалгалтад аяллын өгөгдөл хэрэгтэй; US-05-д аялал болон хэрэглэгч, US-11-д захиалга хэрэгтэй. Хөгжүүлэлтийг mock өгөгдлөөр эхэлж болно, харин Done болгохын өмнө холбоотой урсгалыг шалгана.
4. WIP дүүрвэл шинэ ажил эхлүүлэхгүй; хяналт, алдаа засвар, саад арилгахад тусална.
5. Шинэ хүсэлтийг Product Backlog-д бүртгэнэ. Sprint Goal-д нөлөөлөх өөрчлөлтийг Product Owner болон баг хэлэлцэнэ.
6. Карт шилжихэд хугацаа, хариуцагч, саадыг тэмдэглэнэ. Daily уулзалтаар хамгийн удаан хүлээсэн картыг хэлэлцэнэ.

## Definition of Done

Лаб 3-ын Done шалгуурыг үргэлжлүүлнэ: хүлээн авах шалгуур хангасан, үндсэн урсгалын тест амжилттай, формын шалгалт болон алдааны мэдэгдэл ажилласан, өөр гишүүн код хянасан байна. Хэрэглэгчийн өгөгдөл, суудлын тоо, жолоочийн эрхтэй холбоотой шалгалтыг мөн хийнэ. Энэ репозиторийн симуляц эдгээрийг бодитоор гүйцэтгэсэн гэж мэдэгдэхгүй.

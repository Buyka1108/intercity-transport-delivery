## Зорилго ба хамрах хүрээ

Лаб 2-ын User Story, лаб 3-ын Sprint 1-ийн 7 story (29 SP)-г Kanban урсгалаар зохион байгуулж, WIP хязгаар тогтоох, Lead Time болон Cycle Time тооцоолох, Lean-ийн үрэлгэн зардлыг илрүүлэх.

Эх сурвалж PDF-ийн төгсгөлийн даалгавар нь «Kanban самбар зохион байгуулах, Cycle Time/Lead Time тооцоолох дасгал» юм. Lean шинжилгээ болон CFD-г лекцийн ойлголтуудтай холбон нэмж оруулав.

**Өгөгдлийн тайлбар:** Репозиторид программын хэрэгжилт, бодит ажлын эхлэх/дуусах бүртгэл байхгүй. Энэ лабын төлөв, хариуцагчийн хуваарилалт, D0–D10 хугацаа нь сургалтын симуляц юм. Done нь бодит программ хөгжүүлж дууссан баталгаа биш. Өмнөх лабын Backlog төлвийг өөрчлөөгүй.

## Дасгалын дараалал

1. Sprint 1-ийн 7 story-г To Do-д байрлуулна. Үлдсэн 8 story Product Backlog-д байна.
2. In Progress = 3, Review = 2 гэсэн WIP хязгаар тогтооно.
3. Дараагийн баганад зай байвал ажлыг татаж шилжүүлнэ. Review дүүрвэл шинэ ажил эхлүүлэхээс өмнө review-д тусална.
4. Created, Started, Review, Done хугацааг CSV-д тэмдэглэнэ.
5. `python lab4/calculate_metrics.py` командаар тооцоог гаргана (репозиторийн үндсэн хавтсаас).
6. Хүлээлт, Review-ийн бөөгнөрлийг шинжилж, Lean сайжруулалт санал болгоно.
